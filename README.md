# Trekking Management App V1

A standalone Flask web application for trekking operations, staff assignments, and trekker bookings. Features an Image 5 split-screen hero login page and sidebar administrator dashboard layout.

---

## 🚀 How to Run (1 Simple Command)

### Step 1 — Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 2 — Run Flask App

```bash
py app.py
```

> Open **[http://127.0.0.1:5000](http://127.0.0.1:5000)** in your browser!

---

## 🎨 UI Design (Image 5 Features)
- **Split-Screen Login**: Hero mountain trekker background (`static/images/trekker_hero_bg.png`) with headline *"Explore the World. Trek with Purpose."*
- **Sidebar Admin Dashboard**: Dark navy sidebar (`#071939`) with navigation, stat cards for Total Treks, Registered Trekkers, Pending Staff, Active Bookings, and trek destination management table.
